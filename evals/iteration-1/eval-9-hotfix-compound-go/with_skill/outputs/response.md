### 步骤 1 · P 等级判定

**症状描述**：登录页面白屏，用户输入正确账号密码后页面变成空白。

**P 等级分析**：
- P0（完全不可用）：白屏 = 核心功能（登录）完全不可用，用户无法进入系统
- P1（部分功能炸）：白屏仅发生在登录后，登录页本身可渲染

**判定**：**P0** — 登录是系统入口，白屏阻断所有后续操作，属于完全不可用级别。

### 步骤 3 · 根因分析（Iron Law — 无根因不修复）

**收集症状**：
- 错误表现：登录页面正常渲染，输入账号密码点击登录后页面变白
- 复现条件：输入正确账号密码（错误凭证可能不触发）
- 可能的时间点：最近一次部署/发布后出现

**检查历史类似问题**：
- LESSONS.md 不存在，无历史经验可参考
- `.lessons.jsonl` 不存在

**根因假设**（最多 3 个）：

**假设 1 — 登录成功后路由跳转目标组件崩溃（最可能）**
- 登录 API 返回成功，前端执行路由跳转到首页/仪表盘
- 目标页面组件存在运行时错误（如 undefined 属性访问、渲染异常）
- 白屏 = React/Vue 等框架未捕获错误导致整个组件树卸载
- 佐证：只有正确凭证才触发跳转 → 只有正确凭证才白屏

**假设 2 — 登录响应数据处理异常**
- 登录成功返回的用户数据结构与前端期望不一致
- 前端解析响应时抛出未捕获异常
- 佐证：错误凭证走错误分支（不白屏），正确凭证走成功分支（白屏）

**假设 3 — Token/Session 存储后状态管理崩溃**
- 登录成功后将 token 写入 store/storage
- 状态更新触发全局副作用（如权限初始化、用户信息加载）
- 副作用中的异常导致白屏

**验证计划**：
1. 打开浏览器 DevTools Console，重现白屏，检查是否有未捕获错误
2. 检查 Network 面板，确认登录 API 是否返回成功
3. 在路由跳转目标组件入口加断点，确认是否到达
4. 检查登录成功回调中的数据处理逻辑

**作用域锁定**：
- 前端登录流程相关目录：`src/pages/login/`、`src/router/`、`src/store/`（或等效路径）
- 后端登录 API 仅在确认响应异常时涉及
