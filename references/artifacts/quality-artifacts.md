# 质量工件模板

> TEST.md / REVIEW.md / 交叉评审报告 — 4~5 阶段产出。

---

```markdown

|----|---------|---------|------|
| AC-1 | unit | xxx.test.ts | ✅/❌ |

## 5 轮报告
### 第 1 轮：功能
<结果 + 量化数据>

### 第 2 轮：性能
<结果 + 量化数据 / 跳过理由>

### 第 3 轮：安全
<密钥扫描结果 / OWASP 快查结果>

### 第 4 轮：兼容
<浏览器/平台/版本覆盖情况>

### 第 5 轮：可观测
<日志/监控/告警覆盖情况>

## Bug 清单
| ID | 严重度 | 描述 | 修复验证 | 状态 |
|----|--------|------|---------|------|
```
