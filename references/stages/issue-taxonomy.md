# Issue 分类体系

> 4-测试阶段使用的 Bug 分类和严重度标准。Bug 清单中每个 issue 必须标注类别和严重度。

## 严重度定义

| 严重度 | 定义 | 示例 |
|--------|------|------|
| **Critical** | 阻塞核心流程，导致数据丢失或系统崩溃 | 表单提交导致 500、支付流程中断、数据被无确认删除 |
| **High** | 主要功能不可用，无替代方案 | 搜索返回错误结果、文件上传静默失败、认证重定向死循环 |
| **Medium** | 功能可用但有明显问题，存在替代方案 | 页面加载 >5s、表单验证缺失但提交仍可用、移动端布局错乱 |
| **Low** | 轻微外观或体验问题 | 页脚错别字、1px 对齐偏差、hover 状态不一致 |

## 类别定义

### 1. 功能逻辑（对应第 1 轮：功能）

- AC 未覆盖：验收准则中描述的行为无测试
- 边界遗漏：空输入、极大值、特殊字符未处理
- 状态不一致：并发操作/刷新/回退后状态丢失
- 逻辑错误：条件判断反了、off-by-one、空指针
- 数据完整性：数据丢失、重复创建、部分写入
- 竞态条件：双击提交、过期数据覆盖

### 2. 性能（对应第 2 轮：性能）

- 响应超时：API > 3s、页面 > 5s 加载
- 内存泄漏：长时间运行后内存持续增长
- 并发瓶颈：10+ 并发时错误率飙升
- N+1 查询：列表页逐条查询关联数据
- 资源浪费：大对象未释放、冗余计算、不必要的全量加载
- 吞吐量不足：批量操作在预期数据量下超时

### 3. 安全（对应第 3 轮：安全）

- 密钥泄露：API key / token / password 硬编码或日志打印
- 注入：SQL 注入、命令注入、XSS
- 权限绕过：未认证可访问受保护资源、越权操作
- 数据暴露：敏感信息在响应中明文返回
- OWASP Top 10：按 OWASP 2021 清单逐项快查
- 配置缺陷：CORS 过宽、CSP 缺失、HTTP 而非 HTTPS

### 4. 兼容性（对应第 4 轮：兼容）

- 平台差异：Windows/macOS/Linux 行为不一致
- 浏览器退化：特定浏览器（IE/Safari/旧版 Chrome）功能失效
- 版本退化：新版本破坏旧版 API 契约
- 环境差异：开发/测试/生产环境行为不一致
- 依赖冲突：升级/降级依赖后功能异常
- 编码问题：UTF-8/GBK 边界、时区差异

### 5. 可观测（对应第 5 轮：可观测）

- 日志缺失：错误发生时无日志记录
- 告警盲区：关键指标无监控、阈值未设置
- 指标遗漏：业务指标（转化率/延迟分位数）未采集
- 链路断裂：分布式调用无法追踪全链路
- 诊断困难：错误信息不明确、缺少上下文（request ID / user ID）
- 监控误报：告警过于敏感或过于迟钝

## 严重度 × 类别矩阵示例

| | 功能逻辑 | 性能 | 安全 | 兼容性 | 可观测 |
|---|---|---|---|---|---|
| **Critical** | 核心流程崩溃 | 系统级 OOM | 密钥泄露/注入 | 全平台不可用 | 生产故障无感知 |
| **High** | 主要功能失效 | 核心接口 >5s | 权限绕过 | 主力平台异常 | 关键指标无监控 |
| **Medium** | 非核心功能异常 | 次要接口慢 | 配置偏宽 | 非主流平台异常 | 日志级别不当 |
| **Low** | 边角场景不完美 | 微秒级延迟 | 建议 hardened | 未来版本风险 | 诊断信息不够详细 |

## Bug 清单填写规范

每条 Bug 必须包含：
1. **ID**：ISSUE-NNN 格式，自增
2. **类别**：从上方 5 个类别中选择
3. **严重度**：从 Critical/High/Medium/Low 中选择
4. **所属轮次**：1-5（对应测试金字塔的哪一轮发现）
5. **描述**：预期行为 vs 实际行为
6. **复现步骤**：可操作的具体步骤
7. **证据**：截图路径、日志片段或测试输出（**必填**，不可为空）
8. **修复验证**：每轮循环评审的验证结果
9. **状态**：open / verified / deferred
